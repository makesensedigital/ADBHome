# ADB | Broker de Seguros

Sitio web institucional de **ADB | Broker de Seguros**, productor asesor de seguros
inscripto en la Superintendencia de Seguros de la Nación bajo la matrícula nº 1877.

## Estructura

El sitio es una única página autocontenida: [`index.html`](index.html).
No tiene dependencias externas — todo el CSS, el JavaScript y los gráficos (SVG inline)
viajan dentro del mismo archivo. Se puede abrir directamente en el navegador, sin build
ni servidor.

## Publicación

Desplegado con GitHub Pages desde la rama `main` (carpeta raíz). Cada push a `main`
actualiza el sitio en vivo automáticamente.
